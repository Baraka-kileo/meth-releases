# METH

**Music Experience That Hooks.** One Android app for **YouTube Music and Spotify**: one Home, one Library, one Search, one queue.

## Download
Go to **[Releases](https://github.com/Baraka-kileo/meth-releases/releases)** and download:
- **METH-x.x.x.apk**: the app (Android, arm64)
- **spotify.kxt**: the Spotify extension (only if you use Spotify)

## Install
1. Install the APK (allow installs from your browser or file manager if Android asks)
2. For Spotify: open METH → **Settings → Extensions → Add** and pick `spotify.kxt`
3. Sign in to YouTube Music and/or Spotify

Each release lists everything that's new.

METH is built on the open-source BitChord player (GPL-3.0), with Spotify code from Myspoti and ideas from Melo.
